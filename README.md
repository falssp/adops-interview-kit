## Estrutura

```
adops-interview-kit/
└── Entrevistas/
    ├── interview-prep-unified.html   ← template principal
    ├── interview-prep-cards.html     ← legado
    └── interview-prep-doc.html       ← legado
```

## Template principal

**`Entrevistas/interview-prep-unified.html`**

Feed único e pesquisável com todas as perguntas, respostas e contexto de vaga numa página só.  
Filtros por categoria: Contexto · GMP · CM360 · DV360 · SA360 · Analytics · Situacional · Comportamental · Salário.

🔗 [Visualizar online](https://falssp.github.io/adops-interview-kit/Entrevistas/interview-prep-unified.html)

## Uso para uma nova vaga

1. Copiar `Entrevistas/interview-prep-unified.html`
2. Renomear para `[empresa]-prep.html`
3. Editar o array `ITEMS` no JS com as perguntas e contexto da nova vaga
4. Publicar como artifact no Claude para acesso durante a entrevista
