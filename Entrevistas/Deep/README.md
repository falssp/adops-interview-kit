## Temas cobertos

- **Contexto** — Empresa, papel, diferenciais, gap publisher-side, perguntas para fazer
- **AdOps** — Trafficking GAM end-to-end, pacing, QA de tags, geo-targeting, discrepâncias, frequency cap
- **Técnico** — iframe vs JS, VAST, VMAP, header bidding, hierarquia de prioridades GAM
- **OTT/CTV/DOOH** — OTT vs CTV vs AVOD, DAI/SSAI, publicidade DOOH, specs de criativos
- **Programático** — Open auction/RTB, PMP, SSPs por formato
- **Situacional** — Sub-delivery crítico, discrepância com publisher, múltiplas demandas
- **Comportamental** — Motivação, background agência → publisher, erro + aprendizado
- **Salário** — Ancoragem, range, negociação
